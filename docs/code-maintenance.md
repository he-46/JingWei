# 代码整理：海岸更新、波浪参数与主场景职责

日期：2026-10-26。

## 改动

1. 海岸图按实际受影响区域更新：逐行合并重叠区间，纵向拼接相同区间，避免远距离投石把中间整片地图纳入重算。岸线按区块缓存几何及影响范围，距离查询只检查邻近区块，地形高度保留远处缓存。
2. ocean_parameters.gd 集中维护 CPU/GPU 共用的波形、速度、水平位移、近岸和外围衰减、涟漪形状及限制。海面创建时传入 Shader，瞄准射线高度界限和可见性剔除余量由配置推导。
3. view_controls.gd 从主场景提取输入映射、鼠标观察、水面瞄准与第一人称提示。函数显式接收状态、世界和界面，不保存会跨越换图的场景引用。
4. save_coordinator.gd 独立管理一次后台写入、重复请求合并、手动保存等待和重开归档，通过 started/completed 信号报告状态。暂停、换图、焦点与退出流程仍由主场景协调。

存档格式、填海自由度、升级门槛和资源算法保持原样。后续玩法约束见 [阶段投石与自由填海](gameplay-direction.md)。

## 针对性验证

- 完整 Test.cmd：28 组、2,923 项检查通过，0 失败。
- 海浪现有 137 项检查通过。
- 新增 13 项增量更新检查，以独立整图穷举算法比较每个距离/高度采样，包含分散改动、创建和移除岸线、跨区块角点和地图边缘。
- 分散修改夹具：旧合并区域 70,980 个像素，当前 9,224 个像素，减少约 87%。一次本机无窗口采样中，区域更新约 26.49 ms，整图穷举参考约 192.14 ms；两者不是旧版与新版整局帧率对照，也不代表最低配置表现。
- 自动保存 34 项检查通过，包括慢磁盘期间继续运行、重复请求合并、最新快照、手动保存等待、失败恢复与重开顺序。
- 真实 OpenGL Compatibility 渲染海岸、涟漪及新填岸线，三张固定状态截图与重构前比较，每颜色通道最大差值为 1/255；没有可见外观变化。最大地图也完成渲染检查。

完整回归由 Test.cmd 执行，增量检查已加入默认测试入口。截图与性能临时数据保存在被忽略的 artifacts 目录，不读取或覆盖玩家旅程。

## 当前边界

CPU 岸线计算已局部化，GPU 的 ImageTexture.update 仍上传整张纹理。波纹保持有上限的解析模型，不增加流体反射。主场景仍承担旅程生命周期与 UI 流程，采用逐步拆分，不一次性改写所有模块。独立 EXE 本轮未重新导出。
