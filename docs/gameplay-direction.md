# 后续玩法方向

确认日期：2026-10-26。本文件记录下一轮玩法开发约束，本轮只整理代码，没有新增投石能力或修改数值。

## 阶段性投石方式

随成长阶段解锁新的投石方式，让升级后的操作与反馈产生可感知的变化。具体阶段门槛、操作方式、消耗和效果还需要单独设计及试玩标定；蓄力、扇形等属于候选方案，尚未确定采用。

新投石方式应沿用统一的石料结算、落点范围与资源守恒规则。视觉飞石和涟漪不能重复结算资源；存档迁移应保留已有旅程进度。

## 自由填海

玩家自行决定填海位置、顺序和最终形状，不设计固定路线、指定通道或强制连续铺路任务。新能力解锁也不要求完成特定形状或路线。

保留当前可活动地图、可见范围、投石射程和每格容量等基础限制。阶段成长改变能力，不规定玩家必须先填哪片海。

填海是精卫自己的心愿，成长单位继续使用“修行”。
