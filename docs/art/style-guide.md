# ART-00：美术风格规范 v1

日期：2026-10-14。状态：供 ART-01～07 执行的初始规范，最终观感在可玩样板中复核。以下色值、面数、像素尺寸与性能阈值均为设计目标，不是已完成资产的检测结果。

## 画面方向

风格化 3D、手绘色块与清楚的体块转折。主题是精卫自己的长期心愿：角色有韧劲，环境安静，开山和填海留下可辨认的劳动痕迹。保持连续大陆海岸、正交俯视镜头和米白色简洁 UI。

优先级依次为：角色与资源可辨识、动作反馈、山海变化、材质细节。控制大面积装饰的对比度，让视线优先落在精卫、附近可采石料、穿山甲和落点上。

## 调色板

以现有工程的色彩关系为起点。表中为 sRGB 基准色；通过实机灯光校对最终观感，不把色值直接当作屏幕取色结果。

| 用途 | 基准色 | 使用方式 |
| --- | --- | --- |
| 精卫青羽 | #305F70 | 主体识别色，翅背略深，羽缘以小面积明色分组。 |
| 赤冠与尾羽重点 | #DA684D | 主角的暖色焦点；植被中避免大量使用同样的红色。 |
| 腹部与羽缘 | #FFF0CA | 小面积高明度，帮助轮廓从陆地和海面分离。 |
| 喙与足 | #E9B956 | 用于功能部位，避免与 UI 金圈完全融成一片。 |
| 穿山甲鳞片 | #B3915D / #78533D | 暖褐中间色和深色缝隙，依靠覆瓦结构识别，不靠密集噪点。 |
| 可采石料 | #DED4B9 / #A7B1A3 | 浅暖石与冷灰阴面，整体比邻近地面更容易辨识。 |
| 山体裸岩 | #8D9584 / #657D6B | 中性灰绿，明确岩层与大块断面，控制高光。 |
| 陆地与植被 | #89A77B / #477D60 | 地面平缓，植被稍暗；避免统一的亮绿色锥体。 |
| 沙滩 | #D9CBA4 | 窄幅浅暖色，向湿沙与水下石料过渡。 |
| 浅海 / 远海 / 深海 | #1F615C / #0D3342 / #061829 | 基于现有水面参数，深浅渐变清楚，泡沫只作局部强调。 |
| UI 与文字 | #F4F2E7 / #29413B | 沿用当前主色，控件保持低装饰密度。 |
| 射程与目标 | #E9D192 / #D38B79 | 沿用金色范围与红色超距反馈，同时通过提示文字区分状态。 |

新增同类资产先使用上述共享调色板。一个普通环境物体以主色、阴面色、少量强调色三层组织，细微色差服务于体块，不在所有物体上叠加同等强度的纹理。

## 轮廓与造型

| 对象 | 必须保留 | 需要避免的情况 |
| --- | --- | --- |
| 精卫 | 赤冠、短而明确的喙、展开可读的翅、三簇主尾羽；身体与头部连续。 | 球体之间可见接缝；远景冠羽融成圆点；每根羽毛同等粗细造成锯齿。 |
| 穿山甲 | 长吻、弓背、短腿大爪、逐渐变细的长尾、鳞片叠覆方向。 | 鳞片像独立尖刺；头尾难分；挖掘时整只模型穿入山体。 |
| 山 | 有主峰、次体块、山脚过渡；岩层方向连续；不同山型有独立剪影。 | 全部山体为圆滑土包；只改变尺寸和朝向却宣称不同山型；细碎噪声覆盖大结构。 |
| 碎石场 | 一眼可看出可搬运的石料堆，搬空后变为低矮遗迹。 | 装饰石与资源石完全相同；库存归零仍保留可采指示。 |
| 树与灌木 | 树冠有成组分叉或错落团块，灌木低矮，树脚留出通道。 | 与尖峰山同样的锥形轮廓；树冠长期遮住资源与主角。 |
| 海岸 | 大范围连续，小范围宽窄变化；沙、湿石、浅水之间有层次。 | 视觉陆地与逻辑海格明显错位；海岸变成孤岛或出现可穿行假地面。 |

轮廓以大、中、小三个尺度组织。优先把变化用在外轮廓和大的受光面；正常镜头看不见的细节不增加独立几何体。

## 尺度、镜头与辨识度

世界逻辑格为 4 单位。角色逻辑位置、采集半径、初始射程 4、当前碰撞与飞行高度由规则层决定，正式资产需通过挂载偏移对齐，不能用修改数值补救模型比例。导出轴向、根节点与骨骼命名由 ART-01 形成正式接口。

当前正交跟随镜头基础尺寸为 `29 × (地图边长 / 48)^0.22`，缩放范围 0.6～2.0；全图尺寸为地图边长的 1.6 倍。ART-00 保留此行为，以下指标用于后续样板评审：

- 在 1440×900、默认跟随缩放下，精卫投影高度建议为 32～72 像素，方向可辨；在最远正常跟随缩放下建议至少 16 像素。1152×720 窗口单独复核，不简单以大图缩小代替实机检查。
- 全图用明确的位置标记承接角色识别，不要求玩家从微小角色模型辨认动作；标记建议不小于 8 像素。
- 附近可采石料在灰度图中应仍能和地面区分。对无法从颜色区分的情况，用轮廓、接近提示与选中环补足。
- 金圈、落点环和主角不能互相长期遮挡；超距不能只依靠红绿色差说明。
- 若主角被树或山遮住，应在 ART-07 中比较遮挡淡化、轮廓提示与布局避让的代价，再定实现；不在本包增加新渲染功能。
- 山体体量随储量增长，但受地块及通行空间约束；本轮不改变现有储量到尺寸的算法。轮廓变化不能越出碰撞与布局允许范围。

当前第一轮基线的山脚镜头使用 zoom=0.72，其余跟随镜头使用 zoom=1.0；这些是对比用固定视角，不是新增玩家视角限制。

## 材质和灯光

使用清楚的色块与柔和明暗，羽毛、鳞片、岩石各有不同的面转折。石头以粗糙表面为主，湿石可有有限的低粗糙度区域；神器可有少量金属或发光细节。避免给所有物体使用同样的亮面材质。

初始制作范围：普通岩石/地面粗糙度 0.75～1.0，角色 0.65～0.9，湿石 0.35～0.55，普通环境金属度为 0。以上只适用于会响应这些参数的材质；当前 unshaded 水面依靠着色器自身表现。

默认一盏暖色主方向光加柔和环境光，保留可读的接地阴影。环境不同时增加大量动态灯。当前基线主光旋转 (-52°, -25°, 0°)、能量 0.7、色 #FFF1CE，环境光能量 0.28、色 #C6DFD5，方向阴影距离 90。后续先在相同镜头比较明暗，再调整设置并记录差异。

水面应以大块深浅关系为主，波纹和泡沫密度低于资源与角色细节；填成的新陆地保留石质与湿润边缘。迷雾在边界外遮挡陆海，活动区域内不大面积糊住交互目标。所有效果先在当前 Compatibility 渲染器中验证。

## 初始资产预算

三角形预算按导出后 LOD0 网格计算，不用建模软件四边形数量代替。材质数按可见表面计。此表是制作上限的起点，超出时需在交付记录中说明视觉收益和实测成本，允许据样板调整。

| 资产 | 数量计划 | LOD0 三角形/件 | 材质表面/件 | 纹理与动画预算 |
| --- | --- | --- | --- | --- |
| 精卫 | 1 | 4,000～8,000 | 1～2 | 主贴图至多 1024²，变形骨骼建议 ≤24，每顶点影响 ≤4；六类动作。 |
| 穿山甲 | 1 | 5,000～10,000 | 1～2 | 主贴图至多 1024²，变形骨骼建议 ≤28，每顶点影响 ≤4；四类动作。 |
| 山体 | 样板 1，最终 6～8 型 | 1,500～4,000 | 1～2 | 共享岩层/调色板；每阶段复用材质，避免每座山独占大纹理。 |
| 单石 | 最终约 6 型 | 60～250 | 1 | 共享石材；普通散石不绑定骨骼。 |
| 碎石场 | 最终约 3 组 | 1,500～4,000/组 | 1～2 | 库存用有限层级或实例数量表达，不按真实石数建模。 |
| 树 / 灌木 | 约 3 / 2 型 | 300～900 / 100～350 | 1～2 | 优先不透明几何体；减少大面积透明叶片重叠。 |
| 草丛 | 约 2 型 | 12～60 | 1 | 共享图集或顶点色；远处可隐藏，碰撞按需省略。 |
| 神器 | 3 | 500～1,500 | 1～2 | 图标建议 256²；高亮仅在发现事件短时出现。 |

远景 LOD 初始可尝试约 50% 与 20% 三角形量，再用切换实际画面校正，不能把比例本身当作合格标准。动画以少量骨骼和可混合姿势表达，避免为每帧生成新网格。投石、采集及出土效果需要并发上限和对象复用。

纹理尺寸为单张边长上限参考，不表示每件资产都必须具备全套独立贴图。整体预算在 ART-07 样板实测后冻结；当前不据本表承诺最低硬件要求。

## 性能与发布目标

参考实测设备和现状见 baseline.md。最终目标是已确认设备上的 1920×1080 正常游玩达到稳定 60 帧，帧时间评审参考 p95 ≤16.7 ms；长期卡顿、极端事件峰值和内存另行检查。当前 ART-00 为固定镜头短时空闲负载，不能证明上述发布目标。

最低支持配置、集显表现、笔记本省电模式及 1080p 完整玩法压力结果均待确认；不把当前 RTX 4060 Laptop 测试设备写成最低配置。最终交付需说明是否有低画质档，以及该档实际覆盖的设备。

## 素材来源与审美验收

本规范的色彩与轮廓分析来自项目自身程序模型和实机截图；未导入外部模型、贴图、概念图或 AI 生成资产。技术资料清单见 references.md。以后引入外部资源时，资产清单必须记录来源链接、作者、许可、修改情况与随包声明位置。

ART-07 以同一镜头并排比较角色识别、资源识别、山型差异、海岸层次、运动舒适度与 UI 遮挡。功能检查通过和美术观感认可分别记录；本规范是可执行起点，尚不代表最终美术方案已由玩家试玩确认。
