# 美术试玩候选版更新说明

ART-00～09 集成版，2026-10-15。提供 Windows 64 位 **源码＋内附 Godot 引擎** 试玩；尚未导出独立游戏 EXE，也未上架商店。

精卫现在有赤冠、分层青羽、连贯头喙、分组翅尾、三档负重和七类动作；穿山甲使用长吻、覆瓦鳞甲、长尾与大爪，保持全世界一位工人。八种山体按储量增大，在开采时连续露出岩层，挖尽后留下有限碎石库存，搬空后只剩不可采的山址。

大陆上加入六种石形、三组碎石场、三种树及两类草和灌木。海岸连续接向大陆，海水从浅海向远海、深海渐变；投入的石子形成新陆地与湿边。主角被树或山遮住时出现小位置标记。升高会延长投石距离，原有射程、负重、修行与四档总量规则保持。

采集、起手投石、落水、落地、成陆、开山和神器出土都有对应反馈。三件神器使用正式模型和同源图标，落点声音与投射物共用时序。重复物体按区域绘制，远处减少小装饰、风与动画更新，全图使用简化山体和独立显示预算。

本包完成正式资源、中文字体、四档续档/重选地图/暂停/静音/全图/完成面板核查，并修正神器调色图的 mipmaps、尖峰表面的自阴影细纹。完整检查 1,615 项通过；最终 Git ZIP 的实际 Play.cmd、Test.cmd、Sample.cmd 验证记录见 [发布清单](release-checklist.md)。

试玩方式：完整解压仓库 ZIP，双击 Play.cmd；首次等待内附引擎解压和资源导入。Sample.cmd 可玩固定十万石样板，本次进度不保存；Test.cmd 使用独立测试存档。普通 Play.cmd 继续自动读取、保存旅程；version=3 未改，已有 v2 海岸存档仍按原迁移规则继续。

最终 [实机画面](validation/art09/contact-sheet.jpg) 与 [资源循环短片](validation/art09/resource-cycle.mp4) 来自同一正式运行路径。短片为自动操作的普通流程剪辑，无注入背包或跳过开山时间；省略大部分往返与等待、无声、10 fps，不作为帧率测量。四档完成面板截图属于明确记账的回归夹具，不能当作实际游玩通关时长。

性能参考 [ART-08 同设备、实际 1080p 渲染报告](performance-report.md)：该基线短时场景 p95 1.417～2.489ms，存在一次 28.110ms 尖峰。本包的图集和阴影修正未重测完整性能矩阵，没有据此承诺当前版本在低配、长时间运行或原生全屏下稳定 60 帧。

## 已知问题与范围

- 当前包含完整编辑器引擎和制作源文件，下载、解压体积比独立导出游戏大；首次准备需要可写目录和额外磁盘空间。
- 中文依赖系统字体；尚未验证没有中文字体的 Windows。未测试 Linux/macOS、手柄、触控、最低配置、连续数小时运行或录屏并发。
- 山体碰撞是八层保守包络，双峰山谷不支持在山内穿洞。没有任意挖洞、自动搬运或离线收益。
- 一亿石地图开图仍可能短暂停顿；已有性能报告中的偶发尖峰仍待长时测试定位。
- 项目级对外授权条款、独立 EXE 打包、签名/安装器、商店页及平台审核尚未完成。
