# ART-08 交付：全地图资产扩展与性能优化

日期：2026-10-15。状态：已完成。

普通 Play.cmd 和 Sample.cmd 接入 8 种正式山体、6 种石形、3 组碎石场、3 种树、2 种灌木、2 种草；补充 8 份全图简化山体。24 份新增可编辑 Blender 源文件和 GLB，分别约 10.75 MiB / 1.12 MiB。无新增外部素材和运行依赖；GLB 不重复嵌入环境图集。

所有山使用连续削顶、对应轮廓的八层保守碰撞、有限库存和不可再采的空山址。散石/丢下的石料贴地，三种碎石场有底层和上层堆叠；修正针峰、山脊过低山脚与地面重合的闪烁。规模、储量到体积、一只穿山甲、投石高度增程、资源账本和 version=3 均保持。

32 米区域拆分批次，固定槽位，不因采空迁移；全空批次直接隐藏，剩余实例更新有效包围盒，避免把隐藏石块继续提交绘制。风、草/灌木、工人动画、扬尘、效果和阴影按距离或全图降级；效果隐藏时仍正常结算落点通知，主角位置提示保留。全图使用每型 478 三角形的简化山体，所有装饰与效果池的总量上限不增加。

完整 [资产、编号兼容表及显示预算](../expansion-assets.md)、[四档地图性能报告](../performance-report.md)、[资产总览](../validation/art08/asset-sheet.jpg)、[20 场景联系图](../validation/art08/stress-contact-sheet.jpg) 可直接审阅。源码生成及实机复现工具见 [制作流程](../asset-pipeline.md)。

默认自动检查 1,203 项；实际渲染器专项：山体 113、环境 95、反馈 71、扩展 281、定位 31，均通过，包含四档石料的实际实例颜色初始化。八类山在较大地图均经历开采到搬空；普通路线仍完成 128 石解锁、第一山 1,024 石搬空、累计 1,152 石投入海里。真实 v2 旧档迁移后的 v3 数据和 Sample 对玩家旅程的隔离继续验证。

最终全新源码副本 `artifacts/art/clean-art08-color-final-20261015` 不含本机 `.tools`、`.godot` 缓存或已解压引擎，从随附 ZIP 准备 Godot，全部 1,203 项及 Sample 启动器检查通过；运行路径没有 Blender/Python/ffmpeg 依赖。完整原始日志、帧时间和内存采样留在忽略的 artifacts，可用文档工具重新生成。

性能包含实际 1920×1080 渲染目标、较小窗口预览、四档二十个场景；帧间隔、实际游戏进程工作集、CPU/GPU 与开图/压力夹具准备分别记录。数据限于 ART-00 的 i9-13900HX / RTX 4060 Laptop 设备、短时实时钟采样，未承诺最低配置、长时运行、原生全屏或独立发布构建。
