# ART-08 四档地图性能报告

2026-10-15。数据见 [机器可读摘要](reference/art08/performance-summary.json)、[20 场景实机联系图](validation/art08/stress-contact-sheet.jpg)、[正式资产总览](validation/art08/asset-sheet.jpg)。普通 Play 与 Sample 共用本次模型和分区逻辑。

## 测试条件

ART-00 同一设备：i9-13900HX、RTX 4060 Laptop、NVIDIA 581.57、Windows 10.0.22631、32 逻辑处理器、约 15.81 GiB 物理内存。Godot 4.7.2 正式引擎，Compatibility / OpenGL 3.3、2×MSAA、60Hz 物理、关闭垂直同步、无限制帧率、音频静音。不是独立导出发布包，也未覆盖核显或最低配置。

桌面窗口无法在本环境可靠容纳原生 1080p 窗口，因此本次明确使用 **实际 1920×1080 SubViewport** 渲染全部游戏及 HUD，并通过 1440×810 窗口缩放预览。每个场景保存的实际图像尺寸均检查为 1920×1080。帧间隔包含预览拷贝与测量脚本开销；这与 ART-07 的 1440×900 窗口不是可直接对比的性能提升实验。

固定种子 10213，四档各五场景，每场预热 2 秒、另留 0.25 秒避开截图写盘，再采样真实墙钟 6 秒，共 120 秒计时样本；无 fixed-fps。开图和准备夹具另计，不混入持续帧统计。定时期间普通世界模拟、HUD、遮挡查询与固定效果池正常运行。

| 场景 | 负载说明 |
| --- | --- |
| 普通采集投石 | 驱动真实移动、E 采集与普通投石入口，记录实际成功事件；这段短采样不等同于完整旅程。 |
| 全海域改造 | 计时前用资源守恒的压力夹具填满全部海格，在新陆地上正常模拟；包括地形区块与剩余海陆边界。 |

压力夹具会注入明确记账的测试石料、加速挖山并定位角色，仅用于诊断，不保存玩家旅程。每场结束均用正式存档验证器检查资源守恒及状态。完整真实采集循环另外由 33 项样板路线检查验证。

工作集由宿主每 0.5 秒采样，可能错过更短峰值；系统进程累计峰值另外记录在 JSON，包含开图。引擎静态内存及显存由引擎监视器读取，不等同于系统全部进程或显卡驱动内存。主脚本 CPU 时间通过计时普通 `_process` / `_physics_process` 调用取得，物理只计实际执行的 tick；不包含渲染与测量驱动。渲染 CPU/GPU 是子视口的引擎计时，存在流水线延迟，各列不可简单相加。

## 结论与剩余范围

本设备二十场短时采样的 p95 为 **1.417～2.489ms**，均低于 60 帧的 16.67ms 预算。1000 万普通游玩有一帧超预算，为 28.110ms，约占该场样本 0.018%；其它场景没有超预算帧。因此本次 p95 目标通过，**不能声称所有帧锁定 60 帧或所有设备达标**。

实际游戏进程累计峰值工作集为 **435.5 MiB**（含开图），各场景采样峰值约 341～411 MiB；引擎静态内存峰值 157.7 MiB、监视器显存峰值 122.6 MiB。初次复核发现启动辅助进程只有约 7 MiB，已弃用那批内存数据；最终摘要的进程 ID 与引擎自报 ID 一致。

最大地图的密集山体镜头绘制次数最多，1,092 次；全图 311 次，普通海岸 526 次。该档物理脚本 p95 最重为 2.383ms、最慢 3.690ms，渲染 CPU p95 最重为 1.732ms、GPU 为 2.287ms；主脚本 process p95 ≤0.324ms。由这些计时推断，后续优先优化密集近景的批次/阴影，以及物理 tick 中的世界同步；不能将整帧尖峰直接归为 GPU 瓶颈。开图最多约 859ms，全海域/全山库存压力夹具准备最多约 1.282 秒，均另计，玩家仍可能感受到开图停顿。

本包采用分区批次、共享材质/纹理、固定效果池、远处植被淡出与全图独立预算。所有新 GLB 不重复携带同一张图片，原始 Blender 文件保留可编辑材质。分区不会改变资源位置、碰撞尺寸、采集判定、库存或存档格式。

若较弱设备低于目标，优先关闭近景阴影、关闭 MSAA 或降低实际渲染分辨率，再减少树与草的全局上限；不要增加粒子/装饰或切换更昂贵的渲染器。当前普通游戏没有新增常驻技术设置菜单，这些是开发阶段可复现的降级方向，尚未声称已在低配设备验证。

未覆盖：连续数小时运行、录屏/直播并发、不同电源与温控状态、核显/低端独显、不同驱动、原生全屏 1080p 与独立导出发布构建。尚需 ART-09 的最终引用、分发与发布材料检查。偶发操作系统调度尖峰需要在更长采样中复核，不以短时采样承诺锁定 60 帧。

## 复现

在工程根目录先运行 Test.cmd（确保导入），随后单独执行以下工具；测量时不要同时运行其它游戏检查、视频编码或 GPU 任务：

```powershell
./tools/verify-art-expansion.ps1
./tools/measure-art-expansion.ps1 -Output artifacts/art/art08-performance-accepted
python tools/package-expansion-review.py
./tools/verify-clean-art-copy.ps1 -Destination artifacts/art/clean-art08-new
```

前三者分别生成真实渲染检查、实际 1080p 压力采样、可追溯的摘要/图像。Pillow 只用于整理文档材料；玩家启动不需要 Python、Blender 或 ffmpeg。清洁副本验证从随附 ZIP 解压引擎，不复制本机制作工具或 Godot 缓存。
