# FP-02 有限巡游采样

同一设备、1440×900、Compatibility。四种地图×两档画质，每段真实 8 秒；每版约 64 秒采样，加载与预热不计入每段帧统计。原始测量见 baseline.json 和 current.json。

基线使用 FP-01 正式 PCK，本包使用修改中的工作区源码；两者均由明确指定的编辑器引擎驱动。数据是脚本巡游与表现效果采样，不是发行 EXE 的手动游戏帧率，也不是长时间压力测试。
