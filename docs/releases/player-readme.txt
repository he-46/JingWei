精卫填海 · 衔石成洲
Windows 64 位试玩版 FP-02 · 0.5.1

把整个 ZIP 解压到普通文件夹，然后双击 Jingwei.exe。
Jingwei.exe 和 Jingwei.pck 必须放在一起。无需安装 Godot，也无需联网。

WASD / 方向键：移动
空格：升高（飞得越高，投得越远）；松开下降
E：低空拾石 / 与穿山甲对话
鼠标点击海面 / Q：投石
V：随行 / 第一人称切换，可在设置修改按键
第一人称用鼠标观察，Q / 左键投向准星；U 展开升级栏并释放鼠标
U：升级与神器栏
Tab：全图
Esc：暂停、保存和重选规模
M：静音
F1：操作说明

Esc → 设置：画质、显示、音量、视角与视角切换按键。
第一人称还可调节鼠标灵敏度（0.25–3 倍）和视野（60–100°）。
准星金色表示可投，红色表示超距；底部显示距离或遮挡原因。
靠近石子或穿山甲时，视野中的目标会显示简短 E 提示。
设置即时生效并单独保存，重新开始旅程也会保留。
开图、续档和重选规模时会显示准备进度，完成后即可操作。
首次进入会额外准备投石、填海和神器画面，后续启动会复用引擎缓存。

累计填海 128 石后，唯一的穿山甲会从小山开始自动开采。
山挖完留下有限石料，搬空后不会再生；地上散石采一次消失，随后定时刷新。

进度保存在 %APPDATA%\AzVGames\Jingwei\coast_journey.json。
与 Play.cmd 源码试玩版共用进度。换版本前可备份整个存档文件夹。
画质、显示与声音偏好保存在同目录的 preferences.json，与旅程分开。
退出前可在 Esc 菜单保存；不要同时启动两个版本。

本包是未签名的便携试玩版，已在 Windows x86_64 / OpenGL Compatibility 上验证。
其他硬件、没有中文字体的系统以及长时间运行尚未完成验证。
引擎及第三方许可见 licenses 文件夹。
