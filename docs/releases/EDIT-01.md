# EDIT-01：可以直接打开的编辑器场景

2026-10-22。针对打开 startup、main、jingwei 场景仍然空白的反馈。

## 直接操作

1. 双击 Open-Editor.cmd。若之前已打开角色场景，先关闭该场景标签再重新打开；有未保存改动时先另存副本。
2. 在左下角文件系统找到 `res://scenes/art/editor_coast.tscn`，双击打开。这个场景的海岸、角色、山、树、光照和相机都作为节点保存，无需 F5 生成。
3. 左上角选“场景”，不要停在“导入”。展开 Characters、Mountains、Trees 或 Coast，选中对象，把鼠标移到 3D 窗口内按 F 聚焦。
4. 用移动/旋转/缩放工具，或右侧检查器 Transform 调整。Sun 调灯光，Camera 调构图；F6 运行当前预览，F5 仍进入正式游戏。
5. 精卫本身也可直接打开 `res://scenes/actors/jingwei.tscn`，穿山甲为同目录 `pangolin.tscn`。选中 Model 子节点后聚焦，即可看到原始模型。

## 修改的作用范围

海岸预览是固定的简化摆放场景，不是正式随机地图，不模拟采矿、填海、第一人称或存档。移动其中对象只改变这个预览。预览的海面是静态材质，正式游戏仍使用动态海面。正式地图生成和数值仍由 world.gd / state.gd 控制。

两个角色场景现在直接引用模型，运行时复用已有节点，避免生成第二份。修改角色场景的 Model 子节点会影响使用这个角色场景的游戏内容；动画控制的骨骼和携石状态仍由运行时代码接管。建议复制场景做练习。

验证：静态节点在进入场景树前已经存在，角色初始化和替换后只有一份模型，8 项检查通过；精卫 39 项、穿山甲 55 项、正式模型游戏检查 70 项通过。海岸场景已通过实际渲染查看。保留作者已有的项目配置、启动场景和纹理导入设置改动，未将其纳入本包提交。

本包交付为源码编辑功能；静态预览沿用 scenes/art 的导出排除规则，不增加试玩版内的预览入口。
